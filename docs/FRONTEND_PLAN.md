# План интерфейса

Vue 3 + TypeScript, Vite, Pinia, Vue Router. Библиотеку graph canvas выбрать при реализации по поддержке Vue, лицензии, управлению портами и клавиатурой; название и версию записать в ADR. Не разрабатывать собственный canvas engine ради MVP.

Загрузка CSV доступна из настройки источника: отдельный файловый менеджер не нужен. В срезе выбор единственной организации можно упростить, не убирая tenant context из API.

## Редактор

Слева доступные блоки с поиском, в центре граф, справа выбранный узел. Верхняя панель: имя, «Сохранить», «Проверить», «Запустить», индикатор несохранённых изменений. Run использует только сохранённую revision; при dirty state предложить сначала сохранить и затем запустить, не запускать молча старую конфигурацию.

Настройки source: выбрать asset/connection; transform: field mapping и значения фильтра; destination: таблица/путь/имя файла. Нельзя просить человека писать JSON-конфигурацию. Технические JSON details могут быть диагностическим расширением позже.

Недопустимую связь запрещать с объяснением: «Этот блок не принимает входные данные», «Этот вход уже занят», «Связь создаёт цикл». Проверки client-side повторяют базовые port rules; сервер возвращает ошибки с node ID и field path.

Отличать draft errors от run errors. На конфликте revision не перезаписывать чужую версию: сохранить локальные изменения в памяти и предложить обновление/сравнение. Undo/redo и автосохранение не обязательны для первого среза; предупреждение об уходе с несохранёнными изменениями обязательно.

## Состояния и доступность

Каждая страница: loading, empty, error/retry, success. 401 ведёт на вход с сохранением безопасного return path, 403 объясняет роль. Смена организации очищает cached data прошлой организации; cache keys включают org ID.

Цвет статуса дублируется текстом/иконкой. Узлы выбираются клавиатурой; поля имеют labels, видимый focus и доступные ошибки. Для соединения предложить форму «Выход → Вход», если drag-and-drop недоступен. Первоначальная целевая платформа — desktop browser; на узком экране списки и история доступны, граф может использовать прокрутку.

Polling примерно раз в 2 секунды на активном запуске, с backoff при сетевых ошибках; прекращать на terminal и при уходе со страницы. WebSockets после MVP. Статус запроса браузера не является статусом Execution.

## Проверка UI

Войти → создать проект → загрузить CSV → собрать пример → сохранить → reload → run → дождаться успеха → скачать ожидаемый CSV. Затем неверное поле, запрещённая связь, потеря сети, revision conflict и viewer без кнопок изменения; API всё равно проверяет доступ независимо от кнопок.
