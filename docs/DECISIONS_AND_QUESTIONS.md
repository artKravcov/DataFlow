# Решения и открытые вопросы

## Подтверждено направлением исходного обсуждения

| Решение | Основание |
|---|---|
| Визуальные blocks, без пользовательского кода | Прямое пожелание пользователя |
| Граф, один источник может отдавать в разные места | Прямое пожелание пользователя |
| Аналитики, разработчики, маркетологи | Названная аудитория |
| Обзор текущих/будущих работ, не dashboard ради цифр | Прямое пожелание пользователя |
| Постепенное развитие до реального большого сервиса | Прямое пожелание пользователя |
| Laravel/Vue/TS/PostgreSQL/Redis/Node/Docker | Каркас из обсуждения, принятый как направление |
| S3 убрать со старта; AI/MCP позже | Прямые ограничения пользователя |

## Предложения этого blueprint

| ID | Предложение | Причина / последствие |
|---|---|---|
| P01 | Срез CSV раньше полного MVP | Ранний сквозной результат; DB/REST не потеряны |
| P02 | Один source и без fan-in в MVP | Не проектировать Join преждевременно |
| P03 | Laravel — единственный писатель БД приложения | Единые policies и state transitions |
| P04 | Redis Streams + outbox + internal API | Явный межъязыковой протокол; цена — dispatcher/reconciler |
| P05 | Один active execution на pipeline, без auto-rerun lost work | Меньше опасных повторов внешних записей |
| P06 | Graph snapshot и connection revision check при claim | Редактирование не меняет запрошенную конфигурацию молча |
| P07 | Owner/editor/viewer, connections на уровне организации | Простой понятный доступ; project-level ACL позже |
| P08 | Локальные assets через Laravel, без S3/MinIO | Следует ограничению пользователя, подходит одному host |
| P09 | Полные ограниченные наборы в памяти | Обучаемый runtime; большие данные требуют следующего этапа |
| P10 | Polling в MVP | Меньше инфраструктуры для первой истории выполнения |

Все P — рабочие defaults для реализации, не утверждение об уже существующем коде. Если тест протокола показывает лучшую альтернативу P04, записать ADR и синхронно изменить API/worker/execution docs до развития runtime. Не смешивать два протокола случайно.

## Решить к конкретному этапу

| Вопрос | Когда | Пока использовать |
|---|---|---|
| Название репозитория, Git hosting, лицензия | M0 / до публикации | dataflow локально; без публикации/назначения лицензии |
| Точные версии runtime и библиотек | M0 | Проверить совместимость, закрепить lockfiles |
| Graph library и UI component library | M2 | Минимальный совместимый вариант с port validation |
| Публичный SaaS или self-hosted deployment первым | До внешнего пилота | Локальный Docker Compose |
| Лимиты данных и retention | M3 / до публичного доступа | Лимиты из MVP_SCOPE; ручная административная очистка |
| Приоритет Google Ads/Analytics/Sheets | v2 | Сначала базовые REST/DB/files |
| Join, timezone/DST и branch scheduling semantics | Соответствующий этап | Не реализовывать предположения заранее |

Эти вопросы не требуют остановить подготовку репозитория. Уточнение нужно тогда, когда ответ меняет текущую реализацию; обычные технические детали агент выбирает и документирует сам.
