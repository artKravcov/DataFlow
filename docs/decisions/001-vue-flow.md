# ADR: Canvas редактора графов

Статус: принято для T06.

Для canvas используется `@vue-flow/core` 1.48.2, закреплённый в package.json и lock-файле. Пакет рассчитан на Vue 3 (peer dependency `^3.3.0`, проект использует Vue 3.5), предоставляет перетаскивание, масштабирование, узлы и порты. Лицензия MIT. Проверены [официальное описание](https://vueflow.dev/) и [репозиторий проекта](https://github.com/bcakmakoglu/vue-flow). Редактор сохраняет собственный формат graph API, а не внутреннее представление библиотеки. Для клавиатуры и случаев без drag-and-drop доступна форма соединения; сервер остаётся источником истины для проверки графа.
